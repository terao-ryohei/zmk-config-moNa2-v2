# moNa2 キーマップ組み換え案（2026-10-29）

## 前提（使い手の特性）

- Windows + 日本語ローマ字入力。IME は右親指 2 キー（tap = LANG2/LANG1、hold = レイヤー 1/2）
- 親指が短い。ボールに親指を乗せたまま内側列（15/27）のクリックを押すと親指が握り込み、母指球筋に負荷
- ボールに親指を置いたまま片手でクリック・ドラッグしたい
- ウィンドウ/仮想デスクトップ操作（Win+矢印、Ctrl+Win+矢印、Win+Tab）と記号（括弧類）を多用
- 長音「ー」の `-` がレイヤー 2（右親指 hold）にあり、カタカナ語のたびに右親指がボールを離れる
- Esc が左右親指の同時押しコンボ（38+39）で、右親指を使う

## 方針

1. 右親指はボール専任に近づける。マウス操作中のボタンは右手の人差し指〜薬指のホーム段へ
2. 自動マウス（temp-layer）は「ボールを動かした時だけ」。打鍵で即解除される性質を活かし、
   レイヤー 5 には右手のマウス操作キーだけを置く（左手キーは素通しにして、打鍵で抜けられるようにする）
3. 頻度の高い文字は親指 hold を要求しない位置へ
4. 1 段階ずつ入れて実機で確かめる（段階 1 → 2 → 3）

## 段階 1（実装済み・実機未確認）

### レイヤー 5: MOUSE（ボールを動かすと自動で有効）

```
右手                     
 _    _    _    _    _          ← U/I/O/P は素通し
 _    _   左    右  ｽｸﾛｰﾙ  中     ← H / J / K / L / ;
 _    _   戻る  進む  _    _     ← N / M / , / . / /
```

- J = 左クリック（人差し指ホーム。ドラッグは J 押しっぱなし＋ボール）
- K = 右クリック、`;` = 中クリック
- L = 押している間ボールがスクロール（レイヤー 6 を hold、スクロール処理をレイヤー 3 と 6 で有効に）
- M = 戻る（MB4）、`,` = 進む（MB5）
- 左手の S/D/F クリックは削除（自動マウス後の打鍵 d/f/s がクリックに化けるのを防ぐ）

### レイヤー 0: ベース

| 位置 | 現在 | 案 | 理由 |
|---|---|---|---|
| 15（右内側・中段） | LCLK | `-` | 長音「ー」を親指 hold なしで打てる。クリックはレイヤー 5 へ移った |
| 27（右内側・下段） | RCLK | Esc | Esc を右親指なしで押せる（38+39 コンボは残す） |

その他（レイヤー 1〜4、親指、コンボ）は変更しない。

### 自動マウスのパラメータ

- 発動遅延 100ms（打鍵中の振動で入らない。遅延中のキー入力で発動しない）
- 解除遅延 700ms（旧 moNa2 既定値）。実機で「打鍵がクリックに化ける」なら 500ms 方向へ。DYA Studio で変更可

## 段階 2（段階 1 の実機確認後）

- マウスジェスチャー（zmk-mouse-gesture）: K を「tap = 右クリック / hold + ボールを弾く = ジェスチャー」に。
  候補: 左右 = 仮想デスクトップ切替（Ctrl+Win+←/→）、上 = タスクビュー（Win+Tab）、下 = デスクトップ表示（Win+D）。
  本リポジトリの mouse-gesture は fork（`&mg` / `&mg_set`）で、upstream README の API と名前が違うため要確認
- 精密モード: 押している間だけポインタ速度を半分にするキー（例: レイヤー 5 の H）

## 段階 3（実機で使い込んでから）

- CPI 600 → 800 前後（DYA Studio）。親指が短いので転がす量を減らす
- 打鍵振動で自動マウスが誤発動するなら PMW3610 の移動しきい値を調整
- 動作確認できた時点でモジュールの revision を固定（開発版は `main` 追従のため）

## 採らないもの

- ホームロウモッド: ローマ字は A/S/D/F/J/K/L が高頻度（特に a）で誤判定リスクが高く、日本語入力での有効性を示す根拠が見つからなかった
- クリックの専用ホールド方式（F hold でマウスレイヤー）: 左手が要り、「ボールに触りながら片手で」の要望に反する
